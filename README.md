# Inclusiveness Detection in Bangla Textbooks

This repository contains the research paper and associated code and evaluation materials for our study on inclusiveness detection in Bangla textbooks using large language models and advanced prompting techniques.

## Publication

R. R. Siam, S. I. Mugdha, M. K. Kamrul, A. S. Azad, and S. S. Chowdhury, “Inclusiveness Detection in Bangla Textbooks: Exploring LLMs and Advanced Prompting Techniques,” in *2026 International Conference on Revolutionary Artificial Intelligence and Future Applications (Rev-AI)*, Varna, Bulgaria, 2026, pp. 1–6.

- DOI: [10.1109/Rev-AI70456.2026.11622053](https://doi.org/10.1109/Rev-AI70456.2026.11622053)
- [IEEE Xplore page](https://ieeexplore.ieee.org/document/11622053/)

## Repository contents

- `src/` — research code
- `notebooks/` — evaluation notebook
- `data/` — main dataset file
- `results/` — evaluation results
- `paper/` — paper PDF

## Data and source materials

The dataset was derived from Bangla textbooks. Source books and any data that cannot be redistributed are not included. See `data/README.md` for dataset details and access information.
